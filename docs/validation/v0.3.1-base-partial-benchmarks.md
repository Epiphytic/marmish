## Interpretation and provenance

Seconds = wall_ns / 1,000,000,000. Derived application/file bytes per second = verified payload bytes × 1,000,000,000 / wall_ns. Presentation is rounded only; JSON keeps original integer inputs. Stream payload sums stdin/stdout/stderr. Rsync/copy payload counts verified file content. Whole-operation timers include the installed operation and local terminal/evidence collection; fixture setup and later receipt verification lie outside the timer.

These observations are not network bandwidth, RTT, isolated command latency, transfer-only throughput, steady-state speed, p95, variance or a performance threshold. Different platform directions and asymmetric compression requests are not controlled comparisons. Copy validates a CLI-reported transport codec, while stream/rsync have no inferred negotiated-codec or wire-byte instrumentation. Rsync -z was not requested. Edge/interruption fixture sizes are not folded into these base goodput calculations. Separate finite cold/warm command samples are not included.
