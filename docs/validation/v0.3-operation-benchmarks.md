# Operation benchmarks and measurement boundaries

The [partial base-operation report](v0.3.1-base-partial-benchmarks.md) records 45
verified whole-operation observations from three exact-source cohorts on Linux
AMD64/ARM64 and macOS ARM64. It does not qualify a v0.3.1 release; finite benchmarks
and full post-release qualification remain separate. This document maps the
reproducible workloads and their measurement boundaries.
The [release evidence](v0.3-release.md) retains historical successes and failures.
Those measurements used source `3e93fa46e9f3b96f8ab36581ffe51688ff74eb4a`
carrying metadata 0.2.3, not the published v0.3.0 binaries.

| Operation | Existing native harness | Samples per complete cohort | Goodput numerator |
| --- | --- | --- | --- |
| Finite command | `installed_benchmark.rs`, `installed_local.rs` | Per platform: cold 1, warm 3; 12 total | 262144 verified stdout + stderr bytes; excludes 16384 stdin bytes |
| Binary stream | `installed_streaming_cases.rs` | 9 directed platform pairs | 204800 logical stdin + stdout + stderr bytes |
| Rsync push/pull | `installed_transfer_cases.rs` | 18 directed cases | 32768 logical fixture bytes |
| Native put/get | `installed_transfer_cases.rs` | 18 directed cases | 65536 committed file bytes |
| Interrupted copy/resume | `installed_copy_interruption_cases.rs` | 3 PUT and 3 GET scenarios | Resume: 1310720 minus observed stable post-stop prefix bytes |
| Cancellation and refusals | `installed_edges.rs`, `installed_edge_rsync.rs`, `installed_edge_copy.rs` | Existing edge cohorts | No payload goodput claimed |

Finite wall time starts before detached submit and includes handle parsing, the
second wait CLI and output checks. It ends before later group/receipt checks and
cleanup. Cold means first command-room invocation with configured running daemons;
it is not cold machine/daemon startup or isolated room-setup latency. Warm samples
require the same validated room. The 330-second command deadline shares existing
readiness/work/cleanup bounds of 150/1350/1770 seconds; servers are bounded at 1800.

Stream/rsync/copy wall time includes CLI startup, transport, command/file work,
output capture and subsequent journal/terminal observations. Independent receipt
and cleanup checks occur later. Interruption scenario wall covers preparation,
detach/checkpoint, owned kill, cancel, stable-prefix verification, resume and
proofs. Resume wall covers the resume CLI, immutable-source revalidation and
transfer, ending before later proof observations. Cancellation scenario wall
includes setup and cleanup; it is not request-to-stop latency.

Goodput is numerator divided by observed monotonic wall time. It includes local
work and transport overhead. It is not wire bandwidth, network RTT, compression
ratio or steady transfer speed. Preserve codec, route, platform and direction per
row. One sample per directed case supports no percentile claim; finite summaries
separate cold n=1 and warm n=3. Failed and undispatched cases remain visible and
have no accepted speed. Do not pool unlike cases to produce a latency percentile.

## Reproduction

The [phase plan](../phases/v0.3-test-cleanup.md) defines review, source-freeze and
independent acceptance gates. Use disposable identities and an explicit relay.
These are command templates, not evidence that dispatch occurred. Set exact
reviewed source/candidate/attempt values; workflow provenance rejects mismatches.
Run cohorts serially in the original order, stop on first failure, and reconcile
an ambiguous dispatch before doing anything further:

```sh
gh workflow run streaming-installed.yml -R Epiphytic/marmish --ref master \
  -f cohort="$COHORT" -f candidate_run_id="$CANDIDATE_RUN_ID" \
  -f candidate_run_attempt="$CANDIDATE_RUN_ATTEMPT" \
  -f source_commit="$SOURCE_COMMIT" -f relay=wss://relay.us.whitenoise.chat/
```

Order: `stream-matrix`, `rsync-matrix`, `copy-matrix`, `edge-stream`, `edge-rsync`,
`edge-copy`, `copy-interrupt-put`, `copy-interrupt-get`. Only after all eight pass,
run the existing finite benchmark once against the same unexpired candidate:

```sh
gh workflow run v02-installed.yml -R Epiphytic/marmish --ref master \
  -f cohort=benchmark -f candidate_run_id="$CANDIDATE_RUN_ID" \
  -f candidate_run_attempt="$CANDIDATE_RUN_ATTEMPT" \
  -f source_commit="$SOURCE_COMMIT" -f relay=wss://relay.us.whitenoise.chat/
```

Preserve exact run/attempt/source/target/codec/route pins and context hashes.
Download and independently verify API ZIP sizes, SHA-256, closed member lists,
complete receipts and cleanup; verify the native tool before executing it.
Re-render using the existing native rollup into a fresh output directory and
compare with hosted JSON/Markdown. The eight-cohort auditor and separate finite
artifact/native replay are both required. Generated Markdown alone is not proof.
The accepted report will include raw rows, exact input/output hashes, failures,
NotRun states and the existing finite cold/warm summaries.
