## Local large-payload correctness and elapsed time

Linux AMD64, default-feature debug build, explicit ignored tests, sequential
invocations on an existing shared build cache. Duplex passed 1/1 in 8.45 seconds:
65 MiB+17 bytes each stdin/stdout/stderr, checked with slow consumers and bounded
windows. Fourway copy passed 1/1 in 1075.70 seconds with four concurrent local
actual-helper cases, each 66 MiB+17 bytes (69,206,033 bytes). Hash, metadata,
protocol commit, final ACK, drained pipes and natural helper exit are asserted.

Whole-case timers include local copy execution, helper cleanup/join, hashing,
metadata/protocol assertions and cooperative scheduling. Case setup is staggered;
durations must not be summed into aggregate throughput. File KiB/s divides file
bytes by whole-case seconds and 1024. The ratio uses local protocol stream
bytes, including records, and excludes MLS/Nostr/relay overhead. Synthetic
alternating compressible/pseudorandom regions explain the ratio; it does not
predict general compression benefit. Timings are harness observations, not
network bandwidth, RTT, p95, transfer-only rate or cross-platform comparison.
Observer sample retention caps do not prove product memory bounds. CPU,
contention and filesystem details were not captured. No new methodology or
performance threshold is introduced.
