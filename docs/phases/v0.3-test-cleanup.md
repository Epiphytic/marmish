## Copy-refusal correction

First obtain a compiling failing regression using the authenticated copy actor
and the existing installed refusal validator, then run that same regression after
the narrow validator fix. Test-only visibility may expose the existing fixture;
no production protocol, persistence, authority, permission or timeout change.

For PUT, the client records the independent attempted Launch digest before
publication; the server rejects the changed binding without admitting an Open.
Require the exact client digest and absent server digest, never arbitrary Some.
Validate independent seed session/group, authority, stream, endpoint, unique
record, inactive state, no cancellation, receipts and no filesystem effects.
Assert decoded Conflict/no prior binding for initial, identical and altered
replays. Missing responses cannot prove refusal. Reset only existing fixture
rate-limit bookkeeping (stream 2, peer 8, global 32), never production limits.

For GET, prove the actual local receiver Reserve rejects the changed destination
before a fresh OpenCopy. Only that proven pre-open path permits both fresh records
to be absent. Snapshot retained receiver/seed/index/sentinels. Unexpected behavior
requires an amended reviewed design, not relaxing acceptance.

Add an optional expected digest argument to the existing refusal helper and return
the borrowed matching entry. Independent Launch/seed Binding context is mandatory
iff ResumeChangedBinding. Reject missing or extraneous context. Update every
helper call and Attempt constructor. Preserve the admitted-open equality checks
for ExistingRefusal, ResumeChangedSource and ResumeCorruptCheckpoint. Include
single-field digest, session, group, authority and state mutations.
