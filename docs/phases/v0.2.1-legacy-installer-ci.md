# Retained v0.1 installer CI after native cutover

Status: approved by actual independent [Claude design review r1](../reviews/v0.2.1-legacy-installer-ci-design-r1.md); implementation authorized.
Beads: `marmish-21i`. Worktree base: `39e402773066403d69b814e8b933969d59f7ef16`.

## Cause and scope

The public `scripts/install.sh` is now the reviewed native Rust download bootstrap.
The automatic `installer-validation.yml` archive/PTY tests still extract an
embedded Python block from that path. The managed-runtime proof and its byte-exact
unit test make the same assumption. That is a reference-selection error, not
native installation or transport failure. The actual post-cutover failure is
recorded under the initial-release evidence and this task.

Keep the Python implementation as a pinned optional legacy reference. No product,
public bootstrap, dependency, release version, keychain or transport changes.
No new native acceptance gate: native HTTPS, provider and PTY/setup workflows
already have independent contracts and evidence. Retaining this CI does not make
Python or uv a native installer/runtime dependency.
