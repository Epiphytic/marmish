Pass normal daemon config, the owned optional reporter, canonical installed daemon executable and owned optional fixture roots to the new additive `daemon::registered::run(Config, Option<StartupReporter>, &Path, Option<Vec<CertificateDer<'static>>>) -> Result<()>` async entry. Preserve startup disposition. The entry can exit with a fixed, sanitized failure category for input errors, and immediately dropping an inherited reporter is sufficient to wake the parent for these pre-service failures. It does not retain a reporter clone or report twice after transferring ownership. The no-marker invocation covers foreground and independently reached stock fallback. A private-marker invocation encountering a stock fallback closes the reporter and refuses before continuing into stock, so a failed parent report cannot conceal a live stock child. A no-marker invocation uses the ordinary stock fallback ordering.
