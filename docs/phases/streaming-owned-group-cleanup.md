## Review amendment

Claude Sonnet 5.5 auto design round 1 requested deterministic orchestration tests and explicit error contracts. Introduce a private generic async cleanup boundary taking three lazy operations: final kill `FnOnce() -> io::Result<()>`, exact-child wait `FnOnce() -> Future<Output = Result<ExitStatus>>`, and zero-signal probe `FnOnce() -> io::Result<()>`. Production keeps waitid before this boundary, and the wait operation contains one three-second timeout. The operations retain their normal production implementations; tests inject no global hooks or environment flags. A separate pure classifier is unnecessary.

Initial kill success/ESRCH waits and returns its exact exit status without a probe. Initial EPERM waits exactly once and preserves its exit status only when the subsequent probe returns ESRCH. Initial other errors propagate as Error::Io without waiting. Wait timeout is Error::Timeout; wait I/O errors remain Error::Io; a present group is Error::Invalid("installed_owned_group_present"); denied/unknown probe errors remain Error::Io. Any wait error skips the probe. Never call another nonzero signal after wait. A reused PGID can only cause conservative refusal because the post-reap probe sends signal zero; ESRCH cannot hide an original member remaining in that group. Descendants that leave the owned group remain outside this preexisting harness contract.

Deterministic tests must record exact order: kill(SIGKILL), wait, probe(0) for EPERM→ESRCH with preserved status; no probe on timeout or wait I/O failure; present group, repeated EPERM and other probe errno refuse; initial non-EPERM/non-ESRCH fails without wait; initial ESRCH and success use wait without probe. Native fixture pass proves execution, not that its scheduling entered EPERM. Immediate probing may conservatively refuse unreaped descendant zombies; do not call that physical cleanup success. Retain the existing natural-exit/live-descendant fixture and double-cleanup refusal, plus a live-child cleanup regression.
