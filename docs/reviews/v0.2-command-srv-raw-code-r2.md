  - wrong type

**Production code is unchanged in the parts that matter**
- **No queries to names taken from a response:** the only network call is `pool.lookup(Query::query(owner, SRV))`, and it uses only the caller-supplied owner. Nothing references `Resolver`, `srv_lookup` or `CachingClient` any more.
- **Deadline:** each lookup is still capped by `timeout_at` on the original deadline, with a check before every owner.
- **Options:** request options and `ResolverOpts` are the same as in r1, with case randomization off.
- **Teardown:** the pool is created and dropped inside `block_on`, then the runtime is dropped before the result is returned.
- **Dependencies:** `Message` is a new import from the hickory-proto that's already pinned. No dependency was added.
