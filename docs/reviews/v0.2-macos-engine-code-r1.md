## Non-blocking notes

- **Missing `PIPE` type.** The awk type list doesn't include `PIPE`, which is how Darwin `lsof` labels pipes. Descriptors of that type, or any type not on the list, print a number with no type. That loses information but leaks nothing.
- **Shell options on Linux.** The shared step now starts with `set -euo pipefail` on Linux too. The Linux path has no pipes or unset variables, so this is harmless, but strictly speaking it is a change to the Linux step.
- **Diagnostics can fail the job.** Under `pipefail`, a non-zero exit from `lsof` would fail the macOS job. That fails closed, which is acceptable; just know it can happen.
