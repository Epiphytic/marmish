**Fixes, in brief:**
- **B1:** when a destination is given, require `--` to come straight after it, so `-i`, `--detach`, `--stdin-none` or `--relay` written after the destination produce an error instead of being dropped.
- **B2:** start the autostarted daemon in its own process group or session. Ctrl-C in the CLI currently stops it, and closing the terminal kills it.
- **B3:** make local failures on the command path exit 255. Right now they exit 1, which looks the same as a remote `/bin/false`.
- **B4:** have the journal open check `command_invocations` for the two new client columns before stamping version 5. Otherwise a profile created by the current commit becomes unusable by both the old and new binaries.
