## Scope and limits
- This covers native identity and encrypted message transport only. It does not cover native commands, the installer, the cross-platform command matrix, throughput, legacy v1 compatibility (recorded separately) or a release.
- The live check uses the file backend. Keychain/provider evidence, including the macOS disposable-keychain result in `macos-v2-provider.md`, is a separate core-provider gate and supports no default-ACL or release claim.
- The live driver runs the library owner in-process. It doesn't go through the CLI/daemon IPC socket, which is covered offline only.
- The Arti relay is a single owner on Linux AMD64. No relay-side correlation was available for the direct relay; acceptance rests on decryption plus the durable receipt.
- Timings are single observations: one cold and one warm activation per cell plus four exchanges, not distributions. Earlier failed attempts stay failed.
- `supervisor_reaped_by_this_step` is hard-coded `false` in the fixture, so it isn't evidence either way.
