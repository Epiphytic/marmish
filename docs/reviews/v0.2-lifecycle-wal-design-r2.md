**r1 findings**
1. **Engine database coverage: resolved.** Lines 357-361 say the evidence covers only MDK and Journal and that engine sidecar behavior is unobserved. They require extending the prerequisite to a real `Engine::open_with_master` database with the native-derived key before any lifecycle runtime qualification.
2. **Exact private-file rule: resolved.** Lines 329-331 require the current effective UID, exact `0600` and `nlink==1` through the existing private-file opener, and `check_dir` on `commands/`. Regular and non-symlink are stated for each new sidecar. Hardlink and unexpected-`-journal` negative cases are in the acceptance list (369-370).
3. **No-live-writer prerequisite: resolved, with the corrected handoff.**
   - `daemon::open` acquires the `ProfileLease` at line 38, holds it as `profile`, and calls `native_preflight::check` at line 98. So C holds the lease through preflight, and the amendment's claim matches the code.
   - The amendment says the harness releases its lease before C starts, reaps C, then reacquires before verification. It states that holding the harness lease across C startup would stop C from starting and so could not prove incompatibility.
   - The boundary is an owned `0700` harness root with no other harness owners or workers. A same-UID adversary is explicitly out of scope, and a failed lease acquisition fails closed.

**Also confirmed**
- Main databases, profile/key/config files and preexisting sidecars must stay exact. That includes zero-length sidecars, which count as preexisting.
- The only exception is a sidecar absent from the original snapshot. A new `-wal` must be an empty regular file and a new `-shm` exactly 32,768 bytes. Names must be exact suffixes of the captured database names.
- Production flags, `immutable=1`, checkpoint, journal-mode change, write-capable connections and hand-edited databases are all forbidden.
- A rebuilt preexisting SHM fails closed and needs a new amendment, with no waiver. New SHM contents are not asserted.
- Sidecars are removed only through the existing owned-state cleanup, and not right after C exits.
