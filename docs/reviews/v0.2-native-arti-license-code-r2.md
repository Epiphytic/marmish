2. **Advisory: `void 1.0.2` rests on weaker evidence.** It's pinned through a lightweight tag (`signed_tag_verified: false`), and the doc says so honestly. That's acceptable for build-only notice text. Also, I haven't verified whether rust-void has a root license file under one of the fixed names. 3. **Advisory: the doc can't be re-checked from its own contents.** For the six signed tags it records `true` but not the tag object SHAs or the signer key IDs. Adding those would let someone re-verify later without trusting this run.
