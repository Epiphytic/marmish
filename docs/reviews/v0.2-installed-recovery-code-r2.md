## B1 is resolved
- **The plan is now production code.** `cleanup_plan(unknown, pending_binding, failed)` at `installed_recovery.rs:420-423` is what `Runtime::close` actually calls (`:476-478`). `prepare` gates the whole cancel/prepare/remove block, and `cancel` requires both `prepare` and a failure.
- **The test exercises that function.** `cleanup_plan_gates_the_actual_cancel_and_prepare_decisions` (`:1148`) table-tests the four cases: unknown → neither; pending → neither; known and failed → both; known and passed → prepare only. The old assertion that only checked a value the test had just set is gone.
- **Binding cases are covered (`bind`, `:438-460`):**
  - A missing handle, or a missing digest, returns an error and sets `unknown`.
  - A duplicate key returns an error and sets `unknown`.
  - A changed session now sets `unknown` and errors before anything is inserted; the test checks the map still holds 1 entry.
  - The cap of 2 is enforced with `len() >= 2`; the test shows a third invocation is rejected and the map stays at 2.
- **No second sample after the first fails.** With sample 0 not passed and sample 1 still holding a handle, `validate_record` rejects the record. I traced it and it's rejected by the `stopped` rule (`:841`), not incidentally by another check.

## Other changes I checked
- **Interrupted errors are no longer mislabelled.** `outcome.and(binding)` (`:717`, `:738`) keeps `bind` running unconditionally but now prefers the wait's error, so an interrupted wait is recorded as interrupted.
- **The driver now holds the marker FD.** `hold_recovery_marker` (`fixture.rs:250-265`) opens the marker with `O_NOFOLLOW|O_NONBLOCK`, compares the open FD's identity to the recorded one, and re-verifies it by path. The FD is kept in `Runtime.marker_file`, so the post-exit check at `:718` can't be fooled by inode reuse. The fixture's replacement test now uses this helper.
- **`validate_record` has the new checks (`:819-827`, `:857-865`):**
  - `marker`, `after_reopen` or `ordinary_stop_joined` now require `before_stop`.
  - `engine_cleanup_complete` requires `final_seq`.
  - A quiesced ordinary stop is rejected.
  - `fixture_path` must be absolute, end in the `fixture/main` components, and contain no `*?[]`.
  - The group digest may not equal `handle.submit_sha256`.

  Each check has a mutation test (`:1121`).

- **`running()` boundaries are tested:**
