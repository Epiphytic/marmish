To clear R2-B1, change one test:
1. Free a queue slot before the retry that happens after expiry.
2. Assert the Dispatch is still in `waiting` and not enqueued, and that one credit is still reserved.
3. Add a check that `schedule_active` registers no new Dispatch once the lifetime has expired.

Everything else above is nonblocking. The one with a user-visible effect is NB2: a zero-stdin command whose daemon restarts mid-run may still exit 255.
