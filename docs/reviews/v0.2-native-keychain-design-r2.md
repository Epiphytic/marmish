## Round-1 fixes, checked against the code
1. **Invented notice removed.** Step 5 now asserts `backend=file`, `identity_created` and `keys/`. All three exist in `SetupReport` and `FileProvider`.
2. **Linux lock/unlock by restarting the exact keyring child.** This reuses the start pattern the existing test already proves (`native_linux.rs:66-92`). Any network fetch it would need is confined to the persisted `XDG_DATA_HOME`. The native probe check confirms each state at runtime, so a wrong assumption fails the gate rather than passing it falsely.
3. **D-Bus started directly** with `--nofork`, plus isolation checks that match `validate_isolation`.
4. **macOS split into a privileged outer stage and a same-uid inner stage** through `launchctl asuser` and `sudo -H -u` with `env -i`. This fixes the signalling and process-group problem and pins `HOME`, so preferences can't be written into the runner's account.
5. **Runner keychain snapshot:** a private before/after comparison, publishing only a boolean.
6. **macOS prerequisites:** inputs are staged and their digests rechecked; auto-lock is turned off on the owned keychain only; only a successful reload counts, and `acl_denied_after_unlock` is a failure.
7. **Linux packages:** only missing ones are installed, versions are recorded, and the two binaries must exist.
8. **Exact names and commands:** job, supervisor path, commands and mutation predicates are all given. `--no-grants` meets `grant_choice_required` (`native_setup.rs:124-130`).

**Your macOS correction:** `macos.rs:status()` has no mapping to `Unavailable`, so the code can't produce a Files fallback on macOS. Dropping the missing-default and nonexistent-path case loses no coverage, and the design no longer claims it.

## Implementation notes for code review (not blocking)
- **macOS locked-state item count:** on a locked legacy keychain, an attribute-only search with interaction disabled can return `-25308`, which becomes `locked_or_denied`. Count "no new native items" for step 4 with `List` **after** unlocking, and expect exactly 4. Don't run `List` while locked, or the gate fails for the wrong reason.
- **Inner `PYTHON` on macOS:** use an absolute system interpreter path the account can read, such as `/usr/bin/python3` or the Homebrew path, never one under the runner's home. Record its digest along with the staged inputs.
- **Linux keyring restarts:** reap the old child and wait, with a deadline, until `org.freedesktop.secrets` is released before starting the new one. Then poll the probe within the 15s provider bound, as the existing test does.
- **Failed `init` without mutation:** `daemon::open` reads `config.json` and acquires the lease before `prepare`, and the runtime binding happens only after keys load. The "without mutation" predicate as written is therefore achievable, but compare file bytes, not timestamps.
