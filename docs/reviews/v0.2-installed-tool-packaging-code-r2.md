## Your follow-up fixes

1. **All four source paths must exist.** Each is checked with `git cat-file -e` inside the `set -euo pipefail` step, and the loop exits on the first missing path. The four paths match the `ls-tree` list in the workflow and `SOURCE_PATHS` in `workflow.mjs`.
2. **Tracked files must be unchanged.** `git diff --quiet HEAD --` runs:
   - at verification;
   - before and after the product build (the default `bash -e` shell stops on failure);
   - before and after the feature build.

   The pre-build check also catches changes made by the earlier `cargo test` step.
3. **The product check now catches added files.** The script hashes the product files before and after the feature build and compares the two lists with `cmp`, so it catches added, removed or changed files.

5. **The tests check exact filenames and permissions.** Output names must be exactly the two tools plus `<role>-tooling.json`, with the record at 0444 and the tools at 0555.

## Non-blocking notes

1. **Land order is strict.** `.github/workflows/v02-installed.yml` exists on disk but isn't committed (`git cat-file -e HEAD:…` exits with code 128). The new `cat-file` check means every release candidate build fails until that file is on master. Commit it in the same commit as this change or an earlier one. This is the intended fail-closed behaviour.
2. **Untracked files aren't checked.** `git diff --quiet HEAD` only looks at tracked files. An untracked `.cargo/config.toml` or a file pulled in by `include!` could change the build without being noticed. Only earlier, reviewed steps could create one, so the risk is low. Adding a `git status --porcelain` check later would close it; `__pycache__` is already git-ignored, so the Python steps wouldn't trip it.
3. **The role table is copied in two places.** The producer and its test each map target to role themselves instead of using `installed_records::ROLES`, which only exists when the feature is on. The pending round-trip test should check the record against `ToolingManifest::validate` so a future edit can't let them drift apart.
