**All six r2 refinements are incorporated:**
1. **Dispatch ordering** (lines 122–125, 397–401, 440–441): canonical inspection runs only after the same-turn status check returns Missing. A Found job skips the check and can never become a refusal. Tests are required for this.
2. **Fanout absence** (lines 312–315, 443–444): the doc now says a recorded ACK alone proves nothing. Retirement also checks the stored `list_outbound_fanouts` and queued references through `CommandProtection`. This matches the upstream behaviour at `runtime.rs:4277–4282`.
3. **Shared active predicate** (lines 204–208, 441–442): admission quotas and recovery use exactly the same predicate, including incomplete feeders. Recovery uses the hard ceiling of 32 even if the configured limit was lowered, and never discards workers.
4. **Deferred duplicates** (lines 302–305): after a slot retires, duplicates beyond the 16-per-slot limit are reprocessed as ordinary authenticated replays with current binding, grant and freshness checks.
5. **Limits:**
   - Payload retention is validated within 1 s to 7 days, which fits `marmish_core::Retention`'s 1 s to 365 day range (`config.rs:144–148`). Protected payload is not collected merely because that TTL expires.
   - `engine_policy` maps `invocation_records` to `retained_global` and `active_jobs` to `active_global`.
   - It keeps `cancel_grace=5s` and `drain_grace=2s`, which match the engine defaults at `model.rs:80–81`.
6. **MDK growth** (lines 344–350, 443): the doc reports MDK file and page growth separately from command-table occupancy. It says honestly that pinned MDK keeps request and response rows until the group is deleted. It doesn't delete rows or enable the forbidden retention components, and it makes no claim of bounded total disk use.

**One observation (no change needed):** the 1-second minimum allows a user to configure an output TTL shorter than polling can keep up with. That would show up as honest "expired" gaps rather than a safety problem, and it is a user-selected setting, not the default.
