- **B3 (executable-path detail):** fixed. `validate_error` now requires a leading `/` and no NUL, and runs on both encode and decode through the re-encode.

  - Error detail text is never part of the digest, so NUL-free text is enough here.
- **B4 (literal fixtures):** fixed.
  - `independent_canonical_response_vectors` compares hand-written bytes in both directions for the submit, status, poll and cancel successes, plus a null-detail and a path-detail error. I checked the literal key names and ordering against `phase2.md:234-260`.
