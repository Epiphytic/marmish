`★ Insight ─────────────────────────────────────`
- Gating a field with `#[cfg(test)]` has a blind spot: test builds still compile the field, so a production caller that reads it compiles and passes under `cargo test`. The breakage only shows up in a non-test build. That's why I grepped every non-test use instead of trusting the test logs.
- The adapted tests now ask the production decision function (`next_feeder_operation`) what it would do with the durable row. Before, they read a derived snapshot field. If that logic changes later, these tests will notice.
