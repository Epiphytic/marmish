- **`zombie_members`:** `count <= 0 || count >= capacity || !(count as usize).is_multiple_of(size_of::<i32>())`.
  - Negative and zero: `count <= 0` short-circuits first, so the `i32 as usize` cast never sees a negative value.
  - Upper bound: `count >= capacity` rejects a full or truncated buffer. The later slice `[..count / 4]` is therefore at most 256 of the 257 elements.
  - Divisor: `size_of::<i32>()` is the constant 4.
- **`descriptors`:** `count <= 0 || count as usize > bytes || !(count as usize).is_multiple_of(size_of::<proc_fdinfo>())`.
  - Negative and zero: `count <= 0` is first.
  - Upper bound: `count as usize > bytes` is checked before the multiple test.
  - Divisor: `size_of::<proc_fdinfo>()` is a nonzero constant, 8 bytes.
- **Semantics:** the `Err` returns and the order of the guards are unchanged.
- **Precedence:** `!(x).is_multiple_of(n)` parses as `!((x).is_multiple_of(n))`, because the method call binds tighter than `!`. The result is the same as `x % n != 0`.
