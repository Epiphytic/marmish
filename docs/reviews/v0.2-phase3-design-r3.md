## R1–R3

**R1, the two crash windows: resolved.**
- **First use (lines 216-223):** a prefix holding only the exact `.lock` and at most one `.marmish-native-install.json.tmp-<hex32>` counts as empty. The temp file is unlinked without being read, the prefix is fsynced, and generation 0 is written. Any other entry fails without cleanup. That closes the window after mkdir/lock and during the first receipt write.
- **Staging (lines 307-319):** a durable transaction is enough proof of ownership for its exact `.staging-<txid>` directory (non-symlink, user-owned, 0700), even before a version receipt exists. Cleanup touches only the six fixed basenames, each a user-owned regular file with one link opened without following symlinks, then runs `rmdir` and fsync. There is no recursive walk or wildcard. A partial receipt is deleted, never trusted. If staging is already gone because it was renamed in step 2, it counts as clean, and an explicit retry reuses the version by its receipt (`install_id` matches).
- **Selector and metadata temporaries (lines 288-297):** fixed name templates, and a selector temp is removed only when it is the expected symlink to `next_active`. Sound.

**R2, the state formats: resolved.**
- Line 80 is now `state profile= journal= engine= config= commands=` in a fixed key order.
- The stated values match the source: profile 2 (`identity.rs:195,405`), journal 3 (`journal.rs:132,147`), engine 1 (`store.rs:448,610`). Config 1 matches Phase 2 line 74. `commands=N` is correctly a placeholder that must come from an exported constant.

- Mapping only a proven version mismatch to `incompatible_state`, rather than relabeling every storage failure, is the right refinement.

   - The temporary CLI's directory must not contain a file named `manifest` or `.version-receipt.json`. Otherwise the line 169 rule puts the probe and the temporary installer into installed mode, and they fail.
   - State that the bootstrap keeps the versioned asset basenames in its temp directory, and that the temporary CLI runs in development mode for both the probe and `install`.
