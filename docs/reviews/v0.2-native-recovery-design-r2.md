# Native foundation recovery-check design review, round 2

Actual Claude Code Opus 5.5, session `5022baae-f832-444d-83bf-1048f9f569d1`, `--permission-mode auto`. Recorded before implementation.

**Verdict: APPROVED.** The revised design is ready to implement, though it is not accepted as a fix until the hosted rerun passes. All five earlier findings are closed:

1. **Join loop:** the cold join now uses the same shared bounded-turn driver as the exchange, with its own fixed join deadline unchanged. Activation, `open_conversation` and the initial send are stated as one-shot and stop on error.
2. **Deadline expiry:** the 120-second exchange deadline stays fixed. When it runs out, the final category is `deadline`, and the last recoverable role and label are kept separately.
3. **Terminal transport labels:** the eight labels I named are terminal. Every other transport label is retried within the fixed deadline, matching the daemon. Labels outside the list are reported as `other` and can't extend the time budget.
4. **No outer cancellation:** each tick gets its own per-turn deadline, and the design forbids wrapping a tick in another cancelling timeout.
5. **Post-receipt duplicate sends:** any error from these calls stops the check, and they are never retried. This matches the code: `MdkOwner::send` at `mdk_adapter.rs:1165` returns the existing row's status before any network I/O.

The diagnostics are additive and use fixed value lists with no raw errors. The `ExchangeOwner` test seam is private, and the test obligations cover the scheduling behaviour itself, not just the error classifier.

These notes don't block approval; settle them during the code work:
- **Tokio test feature:** the `full` feature in `crates/marmish-native/Cargo.toml:35` does not include `test-util`, which `start_paused` needs. Add `tokio` with `features = ["test-util"]` under `[dev-dependencies]` only, never the normal dependencies.
- **Roles in the join loop:** `last_recoverable.role` only allows `receiver` or `sender`. Decide which join participant counts as which (for example, the joiner B as `receiver`), and add a test for it.
- **Success value of `operation`:** state that a successful run reports `none` and a deadline exit reports the operation that was running.
- **jq compatibility:** check it against the actual `v02-foundation` workflow filters before publishing.
