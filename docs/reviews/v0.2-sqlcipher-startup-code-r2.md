`★ Insight ─────────────────────────────────────`
- Re-running the same test binary is a common way to get a clean process, but libtest exits successfully when a filter matches nothing. A file the child writes only after its checks pass turns "exited 0" into "actually did the work".
- Putting the sentinel path in the env var does two jobs: it tells the child to run, and it tells it where to report. Because the path is new for each run, an earlier success can't count for a later run.
