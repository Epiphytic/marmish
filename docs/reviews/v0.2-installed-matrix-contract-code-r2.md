**Other changes**

- **`Duration` import.** It now appears only under `#[cfg(test)]`, so the non-test build won't hit an unused-import warning under `clippy -D warnings`.

**Non-blocking**

That would be flakiness, not a driver defect. Widening the pauses and the deadline would help if it shows up.
- **Rollup control.** The mutated records are written with `records::write` on a `Value`. There is no positive control for that exact path with an unchanged value. The later restore uses `write_raw`, so it doesn't cover it. I'm treating this as informational, since the failures also depend on the field-specific checks.
- **Not evidence.** Offline tests and the passing Linux diagnostic don't qualify this driver. Installed all-host acceptance remains required.
