**What I checked**

  - `rest.contains(MARKER)` rejects any second marker, whether on the same line or a later one.
  - The value is read to the first `\n`.
  - It must parse as a JSON `String` and re-serialize byte-identically to the input. That rejects `\r`, trailing whitespace, non-string values, empty values and non-canonical escapes.
  - The quoted form is returned verbatim, so the `conflicting launcher {expected};` containment check still uses the quoted bytes.
  - Stdout over 64 KiB is rejected.
- **Vectors:** every negative vector is rejected for its stated reason.
