### The required changes, checked against the code

**1. Profile receipt and the four checks.** `work` checks absence and captures `cleanup::ProfileReceipt` before setup runs (lines 772–775). The receipt is then verified at each required point:
- after setup (lines 785–791);
- before traffic, inside `activation` ahead of `verify_no_engine`;
- in `close`, before the final no-engine proof (`original`);
- after the joined stop, ahead of `require_no_engine`.

Any failed check fails closed. In `close`, a failed `original` skips the proof but still stops the daemon normally.

The receipt holds an `O_NOFOLLOW|O_DIRECTORY` file descriptor open for the whole runtime. It compares device and inode against a fresh `symlink_metadata`. Because the original descriptor stays open, its inode cannot be reused. The shared helper's own test rejects both a rename-and-recreate and a symlink swap.

**2. Fixed L+1710 proof deadline.** The cleanup deadline is now `deadline.checked_sub(60s).unwrap_or(deadline)` (lines 417–419). The client's no-engine proof uses that deadline, so `stop_no_engine` and the server stop keep 60 seconds at L+1770 for draining. This fixes my earlier nonblocker about the proof starving the stop. If cancel or prepare uses up the time before L+1710, the proof fails closed and the stop keeps its 60 seconds.

**3. Unchanged authority.** The cancel/prepare/`remove_installed` gating, the strict server stop, `cleanup_plan`, the binding and the two-stage sample are all unchanged. The client is still configured without a command count.

**4. Narrow exposures.**
